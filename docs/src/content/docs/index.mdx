```sh
go install github.com/phuquocchamp/jk/cmd/jk@latest
export JENKINS_URL=https://jenkins.example.com JENKINS_USER=jane
printf %s "$TOKEN" | jk auth login --with-token
jk build diagnose team-a/api/main     # why did the last failed build fail?
```

## Why jk

<CardGrid>
  <Card title="Built for agents" icon="seti:json">
    stdout carries only data (JSON when piped). Errors go to stderr as
    `{"error":{"code","message","hint","retryable"}}` with stable exit codes.
  </Card>
  <Card title="CLI and MCP in one binary" icon="puzzle">
    `jk mcp` serves the same 15 operations as MCP tools over stdio, for Claude
    Code and any other MCP client.
  </Card>
  <Card title="Policy you control" icon="approve-check">
    Read only by default. A config profile can allow triggers, or replays and
    stopping builds, scoped by job globs. Flags can only lower it. In MCP
    clients with elicitation, the user approves replay and stop, not the agent.
  </Card>
  <Card title="No Jenkins plugin" icon="rocket">
    Talks to the REST API with a user API token. Uses Pipeline Graph View when
    installed (accurate failed/skipped stages, parallel branches) and falls
    back to `pipeline-rest-api`.
  </Card>
</CardGrid>
