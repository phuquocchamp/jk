```sh
go install github.com/phuquocchamp/jk/cmd/jk@latest
export JENKINS_URL=https://jenkins.example.com JENKINS_USER=jane
printf %s "$TOKEN" | jk auth login --with-token
jk build stages team-a/api/main lastFailed
```

## Why jk

<CardGrid>
  <Card title="Built for agents" icon="seti:json">
    stdout carries only data (JSON when piped). Errors go to stderr as
    `{"error":{"code","message","hint","retryable"}}` with stable exit codes.
  </Card>
  <Card title="CLI and MCP in one binary" icon="puzzle">
    `jk mcp` serves the same 12 operations as MCP tools over stdio, for Claude
    Code and any other MCP client.
  </Card>
  <Card title="Policy you control" icon="approve-check">
    Read only by default. A config profile can allow triggers and replays, or
    stopping builds, scoped by job globs. Flags can only lower it.
  </Card>
  <Card title="No Jenkins plugin" icon="rocket">
    Talks to the REST API with a user API token. Only the usual Pipeline
    plugins are needed for stages, stage logs and test reports.
  </Card>
</CardGrid>
